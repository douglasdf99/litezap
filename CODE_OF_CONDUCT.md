# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Ao participar (issues, pull requests, discussões), você concorda em segui-lo.

Para reportar comportamento inaceitável, escreva em privado para o mantenedor pelo perfil [@douglasdf99](https://github.com/douglasdf99) ou, se envolver segurança, use o canal de [SECURITY.md](SECURITY.md).
